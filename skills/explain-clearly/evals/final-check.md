A

Transformer 是一种让计算机处理文字等序列信息的模型结构。用它生成文字时，模型反复做同一件事：根据已经出现的内容，计算接下来可能出现什么，再选出一小段文字接上去。

它处理的单位叫 token，可以是一个汉字、一个词，也可以是词的一部分。文字进入模型后，每个 token 会变成一组数字；模型还会加入位置信息，让相同的词出现在不同位置时可以被区别处理。

这些数字会经过多层计算。每层的核心步骤叫“注意力”：模型让每个位置与它能看到的其他位置计算匹配分数，再把分数转成权重，按权重合并那些位置的信息。权重越大，那个位置的信息对当前结果的影响就越大。用于逐段生成文字的 Transformer 中，每个位置只能使用自己及之前的位置。这样，模型可以把前面提到的人物、动作等信息带到后面的计算中。每层还会进一步变换合并后的信息，多层计算让不同位置的内容逐步联系起来。

生成下一段文字时，模型用最后一个位置的计算结果，给所有候选 token 打分，再把分数换成概率。例如，输入“他拿起杯子喝了一口”，模型可能给“水”较高的概率。这些概率取决于当前上下文，以及模型此前从文字训练中学到的参数。

程序可以选择概率最高的 token，也可以按概率抽取一个。选出的 token 被加到原文末尾，模型再根据更新后的文字计算下一个 token。这个过程不断重复，直到产生结束标记或达到设定长度，最终拼成我们看到的回答。

B

空调让房间变凉，是因为它把房间里的热量搬到了室外。它用电驱动一种叫“制冷剂”的物质在封闭管路里循环，让室内的一段管路比房间空气冷，让室外的一段管路比室外空气热。热量便能先从房间空气流入制冷剂，再从制冷剂流向室外空气。

这个循环分为四步：

1. **在室内吸热。** 制冷剂以低温、低压的状态进入室内换热器。室内风扇让房间空气经过换热器，较暖的空气把热量传给较冷的制冷剂。制冷剂吸热后，液体逐渐蒸发成气体；空气失去热量，再被风扇送回房间，所以出风变凉了。
2. **用电压缩、升温。** 压缩机把这些气态制冷剂压到更高的压力。压缩机对气体做功，使它的温度升高，达到比室外空气更热的状态。这样，即使室外很热，制冷剂也能向室外放热。
3. **在室外放热。** 高温制冷剂进入室外换热器，室外风扇让空气流过换热器，把热量带走。制冷剂放热后，逐渐凝结成高压液体。这就是室外机运行时吹出热风的原因。
4. **降压、降温。** 液态制冷剂经过膨胀阀，进入低压的一侧。压力降低后，一部分液体立即蒸发，蒸发所需的能量来自制冷剂自身，使剩下的制冷剂降温。它随后再次进入室内换热器，继续吸收房间里的热量。

室内风扇不断让房间空气经过冷的换热器，循环系统不断把吸收的热量送到室外，房间温度就逐渐降低。室外排出的热量还包括空调耗电最终转化的热量，因此比从房间搬出的热量更多。
